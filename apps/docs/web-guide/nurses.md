# 간호사 관리

간호사 관리는 병동 운영의 기반입니다. 근무표를 만들기 전에 누가 실제로 병동에 연결돼 있고, 어떤 구성으로 관리되고 있는지 확인하는 출발점이 됩니다.

## 이 기능이 무엇인가요?

- 병동에 속한 구성원과 팀 구성을 확인하는 기능입니다.
- 근무표 작성에 반영될 근무자 상태를 점검하는 역할을 합니다.
- 구성원 정보 정리, 연결 상태 확인, 팀 단위 운영 점검의 기준 문서가 됩니다.

## 언제 쓰나요?

- 병동에 새로 들어온 뒤 구성원 구성을 먼저 확인해야 할 때
- 근무표 작성 전에 근무자 목록을 정리해야 할 때
- 신청근무나 제약 조건 검토 전에 현재 팀 상태를 다시 봐야 할 때

## 먼저 확인할 것

- 현재 병동에 필요한 팀 구성이 모두 있는지
- 실제 근무표에 반영돼야 할 구성원이 빠지지 않았는지
- 연결 대기 또는 정리가 필요한 구성원이 있는지

## 단계별 설명

1. 병동 운영에 필요한 구성원을 확인합니다.
2. 팀별로 근무자 구성이 적절한지 점검합니다.
3. 필요한 정보를 추가하거나 수정합니다.
4. 근무표 작성에 반영할 수 있도록 구성원 상태를 최신으로 유지합니다.

## 이런 경우 먼저 이 문서를 보면 좋습니다

- 새 병동을 만들고 첫 편성을 준비하는 경우
- 입장 승인 이후 실제 운영 화면을 처음 확인하는 경우
- 근무표 작성 중 누락된 근무자나 팀 구성을 점검해야 하는 경우

## 다음 작업으로 이어지는 흐름

- 병동 진입 직후라면 [병동 생성/입장](/web-guide/wards) 문서와 함께 읽으면 흐름이 이어집니다.
- 실제 편성을 시작하려면 [근무표 만들기](/web-guide/schedule)로 이동합니다.
- 신청근무 반영 전 인원 상태를 먼저 정리하려면 [신청근무 관리](/web-guide/requests)를 함께 확인합니다.
