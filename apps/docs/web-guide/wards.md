# 병동 생성/입장

듀팅 웹에서 실제 협업은 병동 단위로 이뤄집니다. 회원가입을 마친 뒤에는 새 병동을 만들거나, 기존 병동에 입장해 운영 흐름에 합류해야 합니다.

## 이 기능이 무엇인가요?

- 병동 운영을 처음 시작하는 사용자를 위한 `병동 생성`
- 기존 병동 코드로 합류하는 `병동 입장`
- 입장 요청 이후 승인 상태를 확인하는 `승인 대기`

## 언제 쓰나요?

- 수간호사나 운영 담당자가 새 병동을 개설할 때
- 기존 병동 코드로 팀에 합류할 때
- 입장 요청 후 승인 상태를 확인하거나 취소할 때

## 먼저 결정할 것

- 내가 병동을 새로 만들어야 하는가
- 이미 병동이 있고 6자리 코드를 받아 입장해야 하는가
- 입장 후 바로 근무표를 만들 사람인지, 승인만 기다리면 되는지

## 병동 생성 흐름

1. 회원가입 후 `병동 생성`을 선택합니다.
2. 병원명과 병동명을 입력합니다.
3. 병동에서 사용할 근무 종류를 설정합니다.
4. 팀과 근무자 초안을 입력합니다.
5. 저장을 완료하면 병동이 생성되고, 이후 근무표 만들기 화면으로 이어질 수 있습니다.

## 병동 입장 흐름

1. 회원가입 후 `병동 입장`을 선택합니다.
2. 병동에서 받은 6자리 코드를 입력합니다.
3. 병원과 병동 이름을 확인합니다.
4. 맞다면 `입장`을 눌러 요청을 보냅니다.
5. 운영 정책에 따라 바로 입장되거나 승인 대기 상태로 전환됩니다.

## 승인 대기 상태에서 할 수 있는 것

- 현재 어떤 병동에 입장 요청을 보냈는지 확인
- 필요하면 입장 요청 취소
- 승인 후 다시 로그인해 운영 화면으로 진입
