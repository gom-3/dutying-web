# 로그인

로그인은 듀팅 웹 사용의 시작점입니다. 이미 계정이 있는 사용자는 여기서 웹 앱에 진입하고, 계정 상태에 따라 다음 단계가 달라집니다.

## 이 기능이 무엇인가요?

- 카카오 또는 Apple 계정으로 듀팅 웹에 로그인하는 기능입니다.
- 첫 로그인 이후에는 계정 정보 입력, 병동 선택, 근무표 화면 진입까지 이어집니다.

## 언제 쓰나요?

- 이미 가입한 계정으로 다시 접속할 때
- 문서 사이트에서 앱으로 이동해 바로 작업을 시작할 때
- 병동 생성이나 근무표 작성 전에 웹에 진입해야 할 때

## 시작 전에 확인하세요

- 접속 주소는 웹 앱 로그인 페이지입니다.
- 버튼을 누르면 서비스 약관과 개인정보 취급 방침에 동의하신 것으로 간주합니다.
- 아직 계정 생성이 끝나지 않았다면 로그인 후 추가 정보 입력 단계가 이어질 수 있습니다.

## 단계별 설명

1. 로그인 페이지에서 원하는 로그인 수단을 선택합니다.
2. 인증이 완료되면 계정 상태에 따라 다음 화면으로 이동합니다.
3. 이미 병동에 연결된 계정이면 근무표 작성 화면으로 바로 진입할 수 있습니다.
4. 아직 가입 절차가 남아 있으면 회원 정보 입력 또는 병동 선택 화면으로 이어집니다.

## 로그인 후 보이는 대표 흐름

- 계정과 병동 연결이 완료된 사용자: 근무표 만들기 화면으로 이동
- 계정 정보 입력이 필요한 사용자: 회원가입 절차로 이동
- 병동이 아직 없는 사용자: 병동 생성 또는 병동 입장 선택 화면으로 이동

## 자주 막히는 지점

- 원하는 계정이 아니라면 다른 로그인 수단으로 재시도해 계정을 구분하세요.
- 로그인은 됐지만 다음 단계로 넘어가지 않는다면 계정 상태에 따라 추가 입력이 필요한 경우가 많습니다.
- 병동에 연결되지 않은 계정은 바로 운영 화면으로 들어가지 않습니다.
