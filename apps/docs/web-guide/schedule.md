# 근무표 만들기

근무표 만들기는 듀팅 웹의 핵심 작업입니다. 이 문서는 병동에 들어온 뒤 새 근무표를 시작하고, 단계별로 초안을 완성하는 전체 흐름을 설명합니다.

## 이 기능이 무엇인가요?

- 특정 연월과 팀 기준으로 새 근무표를 시작하는 기능입니다.
- 근무자 확인, 제약 조건, 신청근무 확정, 고정 근무, AI 자동 채우기 순서로 진행됩니다.
- 이미 해당 월 근무표가 있으면 조회로 이동하거나 다음 달 근무표를 시작할 수 있습니다.

## 언제 쓰나요?

- 새 달의 근무표를 처음 만들 때
- 현재 월 근무표가 없는 팀에서 편성을 시작할 때
- 기존 신청근무와 제약 조건을 반영해 초안을 생성해야 할 때

## 시작 전에 확인하세요

- 병동과 팀 연결이 완료되어 있어야 합니다.
- 해당 팀에 근무자가 등록되어 있어야 합니다.
- 신청근무와 고정 근무를 반영하려면 관련 데이터가 먼저 정리되어 있으면 좋습니다.

## 단계별 설명

1. 근무표 만들기 화면에서 현재 월 또는 다음 월 근무표 생성을 선택합니다.
2. `근무자 확인` 단계에서 실제로 투입할 근무자를 점검합니다.
3. `제약 조건` 단계에서 우선순위와 규칙을 확인합니다.
4. `신청 근무 확정` 단계에서 제출된 요청을 승인 또는 반려합니다.
5. `고정 근무` 단계에서 반드시 반영해야 하는 근무를 확인합니다.
6. `AI 자동 채우기` 단계에서 설정한 조건을 바탕으로 초안을 생성합니다.
7. 생성된 결과를 검토한 뒤 근무표 화면으로 이동해 최종 조정합니다.

## 이미 근무표가 있는 경우

- 같은 월 근무표가 있으면 바로 조회 화면으로 이동할 수 있습니다.
- 현재 월 편성이 끝난 팀은 다음 달 근무표를 연속해서 만들 수 있습니다.
