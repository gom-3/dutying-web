# 신청근무 관리

신청근무 관리는 근무표 작성 전에 반드시 점검해야 하는 운영 단계입니다. 이 문서는 신청된 요청을 어떻게 확인하고, 어떤 시점에 반영 판단을 해야 하는지 기본 흐름 중심으로 정리합니다.

## 이 기능이 무엇인가요?

- 병동 구성원이 제출한 신청근무를 확인하는 기능입니다.
- 근무표 작성 단계에서 요청을 승인하거나 보류, 반려 판단하는 기준점이 됩니다.
- 요청 반영 결과는 이후 근무표 초안과 최종 조정에 직접 영향을 줍니다.

## 언제 확인하나요?

- 근무표를 작성하기 전에 요청 현황을 먼저 볼 때
- 작성 중간에 신청 내용을 반영해야 할 때
- 마감 이후 예외 요청을 점검할 때

## 시작 전에 확인하세요

- 현재 작성하려는 월과 팀이 맞는지 먼저 확인합니다.
- 병동 구성원이 제출한 요청이 모두 수집되었는지 점검합니다.
- 승인 기준이 팀 안에서 정리되어 있지 않다면 운영자끼리 먼저 기준을 맞추는 것이 좋습니다.

## 단계별 설명

1. 병동 또는 근무표 화면에서 신청근무 현황을 확인합니다.
2. 요청별로 반영이 필요한지 검토합니다.
3. 승인, 보류, 반려가 필요한 요청을 구분합니다.
4. 확정한 결과를 바탕으로 근무표 작성 단계에 반영합니다.

## 이런 기준을 먼저 보면 좋습니다

- 같은 날짜에 요청이 과도하게 몰려 있는지
- 특정 근무 유형에 편중된 요청이 있는지
- 이미 정해진 제약 조건과 충돌하는 요청이 있는지
- 구성원 간 형평성을 해치지 않는지

## 다음 작업으로 이어지는 흐름

- 요청 정리가 끝났다면 [근무표 만들기](/web-guide/schedule)에서 확정 단계를 진행합니다.
- 요청 반영 전에 구성원 상태를 다시 확인해야 한다면 [간호사 관리](/web-guide/nurses)를 함께 봅니다.
