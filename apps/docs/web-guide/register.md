# 회원가입

회원가입 단계에서는 듀팅이 계정을 실제 근무자 정보와 연결할 수 있도록 기본 정보를 입력합니다. 단순히 계정을 만드는 단계가 아니라, 이후 병동 생성 또는 병동 입장으로 이어지는 출발점입니다.

## 이 기능이 무엇인가요?

- 이름, 성별, 전화번호, 입사일, 프로필 이미지 같은 기본 정보를 등록하는 단계입니다.
- 근무표에 본인을 포함할지 여부도 여기서 설정합니다.
- 입력이 끝나면 병동 생성 또는 병동 입장 흐름으로 넘어갑니다.

## 언제 쓰나요?

- 처음 로그인한 뒤 아직 계정 설정이 끝나지 않았을 때
- 기존 병동에 합류하기 전 개인 정보를 먼저 등록해야 할 때
- 새 병동을 직접 만들기 전에 운영자 계정을 준비할 때

## 단계별 설명

1. 로그인 이후 회원 정보 화면으로 이동합니다.
2. 기본 제공 프로필 이미지를 랜덤 변경하거나 직접 업로드합니다.
3. 이름, 성별, 전화번호, 입사일을 입력합니다.
4. 본인이 교대 근무자인지 선택합니다.
5. `다음`을 눌러 병동 선택 단계로 이동합니다.

## 입력 시 알아두면 좋은 점

- 이름은 한글 또는 영문 기준으로 입력합니다.
- 전화번호는 숫자만 이어서 입력합니다.
- 입사일은 `YYYY-MM-DD` 형식으로 입력해야 합니다.
- `교대 근무자` 여부는 이후 근무표 표시와 연결됩니다. 교대 근무자로 설정하면 근무표에 포함되어 일정 배치 대상이 되고, 비교대 근무자는 근무표에서 제외됩니다.
- 가입 후에도 프로필 설정에서 이름, 전화번호, 입사일, 프로필 이미지를 수정할 수 있습니다.

## 가입 후 이어지는 선택

- 병동을 새로 운영할 예정이라면 병동 생성
- 이미 만들어진 병동에 합류할 예정이라면 병동 입장
- 이미 입장 요청을 보냈다면 승인 대기 화면에서 상태 확인
