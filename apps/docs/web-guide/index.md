# 웹 사용자 가이드

이 섹션은 듀팅 웹에서 병동을 운영하고 근무표를 만드는 사용자를 위한 안내입니다. 화면을 하나씩 설명하기보다, 실제로 사용자가 밟는 순서대로 문서를 배치했습니다.

## 이 문서부터 읽으면 좋은 사람

- 처음으로 듀팅 웹에 로그인하려는 사용자
- 가입 후 병동을 만들거나 기존 병동에 합류해야 하는 사용자
- 병동 설정을 마친 뒤 첫 근무표를 만들어야 하는 관리자

## 추천 읽기 순서

1. [로그인](/web-guide/login)
2. [회원가입](/web-guide/register)
3. [병동 생성/입장](/web-guide/wards)
4. [근무표 만들기](/web-guide/schedule)

## 운영 중 참고 문서

- [신청근무 관리](/web-guide/requests)

## 웹 문서의 역할

- 웹 문서는 병동 생성, 병동 입장, 근무표 작성처럼 운영자 중심 작업을 다룹니다.
- 모바일 문서는 추후 개인 일정 확인과 신청근무 제출 같은 사용자 흐름을 채울 예정입니다.
- 공통 개념은 [시작하기](/getting-started/)와 [FAQ](/troubleshooting/faq)에서 연결합니다.
