## 어떤 문서를 담나요?

- **시작하기**: 문서 사이트의 범위, 플랫폼 구분, 빠른 진입 링크
- **웹 가이드**: 로그인부터 병동 진입, 근무표 운영까지 웹 중심 안내
- **모바일 가이드**: 추후 모바일 앱 설치, 일정 확인, 신청근무 흐름 문서화 예정
- **문제 해결 / FAQ**: 사용자 문의가 반복되는 항목을 축적하는 공간
