# FAQ

## 웹 문서는 어디서 시작하면 되나요?

처음에는 [웹 사용자 가이드](/web-guide/)에서 전체 흐름을 확인한 뒤, 계정이 있으면 [로그인](/web-guide/login), 처음 사용하는 사용자라면 [회원가입](/web-guide/register)으로 이동하는 흐름을 권장합니다.

## 문서 사이트와 실제 앱은 어떻게 다른가요?

문서 사이트는 사용법을 설명하는 곳이고, 실제 작업은 웹 앱에서 수행합니다. 제품 소개와 유입은 랜딩 사이트가 담당합니다.

## 모바일 앱 가이드는 아직 없나요?

이번 1차 구축에서는 구조만 먼저 확보했습니다. 이후 모바일 앱 설치, 로그인, 근무표 확인 흐름 문서를 같은 사이트 안에 추가할 수 있습니다.

## 스크린샷이 아직 없는 이유는 무엇인가요?

이번 작업의 목표는 문서 사이트 완성이 아니라, 독립 실행 가능한 docs 앱과 확장 가능한 정보 구조를 만드는 것입니다. 상세 이미지와 운영 정책은 후속 문서 작업에서 점진적으로 보강할 수 있습니다.
