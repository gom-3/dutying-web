# 모바일 가이드

모바일 가이드는 이번 1차 이관 범위에는 포함되지 않지만, 문서 사이트 안에서 역할을 미리 분리해 둡니다. 이렇게 해야 현재 웹 문서가 운영자 가이드에 집중되면서도, 이후 모바일 사용자 문서를 자연스럽게 확장할 수 있습니다.

## 이번 단계에서 이 섹션의 역할

- 웹 문서와 모바일 문서의 경계를 명확히 유지
- 이후 추가할 모바일 문서의 자리 확보
- 같은 브랜드 안에서 플랫폼별 탐색 구조 유지

## 이후 추가될 후보 문서

- 앱 설치와 첫 로그인
- 내 근무표 확인
- 신청근무 제출
- 알림과 동기화 관련 안내

## 웹 문서와의 관계

- 병동 생성, 병동 입장, 근무표 작성은 [웹 사용자 가이드](/web-guide/)에서 설명합니다.
- 개인 일정 확인과 신청근무 제출은 모바일 가이드에서 다루는 것이 자연스럽습니다.
- 공통 개념은 [시작하기](/getting-started/)와 [FAQ](/troubleshooting/faq)에서 연결합니다.
