# 시작하기

`Dutying Docs`는 웹과 모바일 사용자 가이드를 한 곳에 모으기 위한 문서 사이트입니다. 이번 1차 구축은 **웹 사용자 가이드**를 기준으로 시작하지만, 상위 정보 구조는 처음부터 플랫폼 확장을 고려합니다.

## 문서 사이트 역할

- 제품 소개와 유입: 랜딩 사이트
- 실제 웹 서비스 사용: 웹 앱
- 사용 가이드와 도움말: 문서 사이트

문서 사이트는 마케팅 페이지를 대체하지 않고, 앱 UI를 그대로 복제하지도 않습니다. 사용자가 작업 흐름을 이해하고, 필요한 화면으로 다시 돌아갈 수 있게 돕는 것이 목적입니다.

## 현재 정보 구조

### 1. 시작하기

- 문서 범위 설명
- 플랫폼별 문서 진입점 안내

### 2. 웹 사용자 가이드

- 로그인과 계정 진입
- 회원가입과 기본 정보 입력
- 병동 생성 또는 병동 입장
- 근무표 만들기와 운영 보조 문서

### 3. 모바일 가이드

- 현재는 자리만 확보
- 이후 설치, 로그인, 근무표 확인, 신청근무 흐름 추가 예정

### 4. 문제 해결 / FAQ

- 계정, 권한, 병동 접근, 근무표 편집 관련 반복 질문 축적

## 문서 작성 원칙

- 사용자 여정을 기준으로 페이지를 추가합니다.
- 웹과 모바일 공통 개념은 상위 소개 문서에서 설명합니다.
- 플랫폼별 세부 단계는 각 가이드 섹션에서 분리합니다.
- 스크린샷이나 영상은 구조가 안정된 뒤 페이지별로 점진적으로 보강합니다.
